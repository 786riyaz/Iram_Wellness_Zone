Create a complete, modern, responsive, and professional website for my weight loss and wellness community called **"Iram Wellness Zone"**.

## Important Requirements

* **Use only HTML5, CSS3, and Vanilla JavaScript.**
* **Do NOT use React, Next.js, Vue, Angular, jQuery, Tailwind CSS, Bootstrap, or any other framework or library.**
* The website must be built using only plain HTML, CSS, and JavaScript.
* The project should be lightweight, fast, and easy to understand.
* The website must be fully compatible with **GitHub Pages** hosting.
* All assets should be organized into separate folders (`css`, `js`, `images`, `icons`, etc.).
* Use semantic HTML and write clean, well-commented code.
* The website should work offline except for optional Google Fonts.
